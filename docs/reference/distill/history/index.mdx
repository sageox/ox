## ox distill history

Inspect distilled daily/weekly/monthly summary entries

### Synopsis

Read-only commands for listing, showing, and dumping distilled summary entries in memory/daily, memory/weekly, and memory/monthly under a team-context root. With no subcommand, behaves like `ox distill history list`.

```
ox distill history [flags]
```

### Options

```
      --all-teams       merge entries across every registered team context
      --format string   output format: json|text (default "json")
  -h, --help            help for history
      --layer string    layer to read: daily|weekly|monthly|auto (default "auto")
      --limit int       cap the number of entries returned (0 = unlimited)
      --since string    start of window (duration like 24h, or absolute RFC3339/YYYY-MM-DD[THH:MM[:SS]])
      --team string     team slug, id, or name (defaults to the repo's active team)
      --tz string       IANA timezone for naked absolute timestamps (e.g. America/Los_Angeles)
      --until string    end of window (absolute timestamp; defaults to now)
```
