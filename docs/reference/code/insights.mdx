## ox code insights

Show planning-relevant code insights (hotspots, contention, recent activity)

```
ox code insights [flags]
```

### Options

```
      --days int    time window in days (default 14)
  -h, --help        help for insights
      --json        structured JSON output for agents
      --limit int   max rows per section (default 10)
```

```
  -v, --verbose          enable verbose output (default: false)
```
