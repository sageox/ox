## ox team open

Open a team's dashboard in the browser

### Synopsis

Open the SageOx web dashboard for a team.

Name the team as a positional argument or with --team; with neither, opens this
repo's team.

```
ox team open [team] [flags]
```

### Options

```
      --endpoint string   SageOx endpoint URL (for multi-endpoint repos)
  -h, --help              help for open
      --team string       Team ID or slug to open (defaults to this repo's team)
```
