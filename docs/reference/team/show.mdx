## ox team show

Show one team's details

### Synopsis

Show a single team: its identity, where its Team Context lives on disk, how
recently it synced, and how many coworkers it has.

Name the team as a positional argument or with --team; with neither, shows this
repo's team.

Example:
  ox team show
  ox team show acme
  ox team show --team acme
  ox team show --json

```
ox team show [team] [flags]
```

### Options

```
  -h, --help          help for show
      --json          Output as JSON
      --team string   Team ID or slug to show (defaults to this repo's team)
```
