## ox upgrade

Upgrade ox to the latest version

### Synopsis

Detect how ox was installed and upgrade using the appropriate method (Homebrew, go install, or manual download).

```
ox upgrade [flags]
```

### Options

```
  -h, --help            help for upgrade
      --json            output as JSON
      --target string   pin upgrade to a specific version tag (e.g. v0.18.0); empty = latest from GitHub releases API
```
