## ox murmur

Publish a coordination signal to other AI coworkers

### Synopsis

Murmur publishes a short-lived coordination signal that other AI coworkers
on the same repo (or team) will hear as a whisper.

Examples:
  ox murmur --topic=lint "ESLint rule failing in src/auth/"
  ox murmur --scope=team --topic=architecture "API contract v3 rolling out"
  ox murmur --importance=critical --topic=conflict "Modifying shared auth middleware"
  ox murmur '{"content": "Fixing lint rule X", "topic": "lint"}'

Murmurs expire in 24 hours. For durable team rules (conventions, policies,
post-incident learnings), see 'ox guide murmur-vs-rule' and 'ox guide team-rules'.

```
ox murmur [content] [flags]
```

### Options

```
      --agent-id string     agent ID (falls back to SAGEOX_AGENT_ID env)
      --files string        comma-separated repo-relative file paths being modified
  -h, --help                help for murmur
      --importance string   importance level: critical, normal, ambient (default "normal")
      --scope string        scope: ledger (this repo) or team (all repos) (default "ledger")
      --topic string        topic slug for filtering (e.g., lint, architecture, conflict) (default "general")
```
