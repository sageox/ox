## ox murmur status

Show murmur delivery status and per-coworker rate limit state

### Synopsis

Show the last murmur from each active coworker and whether they are
currently rate-limited or ready to publish.

Reads the current and previous hour from the ledger — no murmurs are sent.

Examples:
  ox murmur status            # table view
  ox murmur status --json     # JSON for scripting

```
ox murmur status [flags]
```
