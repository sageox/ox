## ox murmur pause

Pause murmur nudging for this session

### Synopsis

Pauses automatic murmur nudges for the current agent session. Other agents' murmurs are still relayed; only nudge generation is suppressed.

```
ox murmur pause [flags]
```

### Options

```
      --agent-id string   agent ID (falls back to SAGEOX_AGENT_ID env)
  -h, --help              help for pause
```
