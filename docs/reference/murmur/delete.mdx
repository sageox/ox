## ox murmur delete

Delete a murmur by ID

### Synopsis

Remove a murmur from the ledger or team context.

The murmur ID can be found via 'ox murmur list --json'.

Examples:
  ox murmur delete 019d3201-87d2-7693-a6ef-aba37863fd18
  ox murmur delete 019d3201-87d2-7693-a6ef-aba37863fd18 --scope=team

```
ox murmur delete <murmur-id> [flags]
```

### Options

```
  -h, --help           help for delete
      --scope string   scope: ledger (this repo) or team (all repos) (default "ledger")
```
