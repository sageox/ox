## ox index

Index code and project data for search

### Synopsis

Build searchable indexes from code, GitHub PRs, issues, and other project data.

Run with no subcommand to index all available sources. Use subcommands to
index specific sources individually.

```
ox index [flags]
```

### Options

```
  -d, --days int      max days of GitHub history to fetch (default 30)
      --full          wipe all indexes and rebuild from scratch
  -h, --help          help for index
      --issues-only   index only issues (GitHub)
      --no-push       extract to ledger without pushing
      --prs-only      index only pull requests (GitHub)
```
