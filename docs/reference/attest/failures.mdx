## ox attest failures

Read the verified failure index from a hosted publication

```
ox attest failures <attpub_id> | --latest [flags]
```

### Options

```
  -h, --help     help for failures
      --json     emit structured JSON
      --latest   select the newest complete hosted publication
      --text     render a compact terminal summary
```
