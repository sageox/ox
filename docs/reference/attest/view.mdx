## ox attest view

View a hosted Attest publication

```
ox attest view <attpub_id> | --latest [flags]
```

### Options

```
  -h, --help     help for view
      --json     emit structured JSON
      --latest   select the newest complete hosted publication
      --text     render a compact terminal summary
      --web      open the stable SageOx Attest page
```
