## ox attest record

Mint an attestation from a red/green run pair

### Synopsis

Write the durable record of a red-first proof.

This is the artifact that cannot be rederived. It captures a failure produced by
a break that no longer exists in the tree, so a field missing at mint time can
only be recovered by re-applying that break at the original commit — often
against an environment that no longer builds. Mint it complete or lose it.

The record lands beside the feature it attests, in this repo, and is committed in
the same change that earns the stamp.

  ox attest record \
    --capability team-management/team-visibility#a-non-member-is-denied... \
    --break "team gate inverted — checkTeamAccess returns true for every caller" \
    --red-run run_01991f3c-8a2e --green-run run_01991f47-b105 \
    --red-verbatim-file /tmp/red.txt --step 4 \
    --step-text "Then Marcus sees Access Required" \
    --landed-on-claim-step \
    --surface app/team/settings/layout.tsx --surface internal/handlers/team/access.go

```
ox attest record [flags]
```

### Options

```
      --break string               what was broken, in the language of the claim (required)
      --break-diff-file string     the applied patch, hashed to prove a break existed
      --capability string          capability id or an unambiguous substring (required)
      --corpus string              corpus directory relative to the repo root (default tests/acceptance)
      --dry-run                    validate and print without writing
      --green-run string           run id of the run that passed with the break removed
  -h, --help                       help for record
      --json                       structured JSON output for AI coworkers
      --landed-on-claim-step       the red landed on the step naming the behavior
      --red-run string             run id of the run that went red
      --red-verbatim string        failure text inline (prefer --red-verbatim-file)
      --red-verbatim-file string   file holding the failure text, exactly as emitted
      --repo-key string            opaque repo key (default: the repo directory name)
      --step int                   1-indexed step the failure landed on
      --step-text string           text of the step the failure landed on
      --surface stringArray        a file or route the run exercised; prefix ambiguous values with file: or route: (repeatable)
      --verdict string             override the derived verdict (clean|ambiguous|inconclusive)
```
