## ox brief

Show what SageOx gave this session

### Synopsis

Show what SageOx gave this session: the ox calls your AI coworker made, how
much context ox put in front of the model (estimated tokens), which team items
were surfaced by name, and which of those the AI coworker reports it used.

When called by an AI coworker it emits JSON with a pre-rendered display and
guidance; in a bare terminal it prints the same report. --me rolls up your
recent sessions; --team shows a team-wide aggregate only — never who did what.

In the session view, calls.recent in the JSON lists the 10 newest ox calls;
--recent N widens it (0 = every call). The display text is unchanged.

```
ox brief [flags]
```

### Examples

```
  ox brief                     # this session
  ox brief --session <name>    # a recorded session in the Ledger
  ox brief --me --since 14d    # your recent sessions, one row each
  ox brief --team              # team-wide aggregate (no per-person data)
  ox brief --json              # structured report for AI coworkers
  ox brief --json --recent 0   # every ox call in calls.recent
```

### Options

```
  -h, --help             help for brief
      --json             structured JSON report for AI coworkers
      --limit int        maximum sessions for --me (default 10)
      --me               roll up your recent sessions, one row each
      --recent int       session view: ox calls listed in the JSON calls.recent (0 = all) (default 10)
      --session string   report a recorded session by name instead of the current one
      --since string     window for --me and --team (e.g. 7d, 24h, or an ISO date) (default "7d")
      --team             team-wide aggregate across all coworkers' sessions (no per-person data)
```
