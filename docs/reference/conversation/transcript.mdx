## ox conversation transcript

Read a transcript slice by cue range or time window

### Synopsis

A transcript slice of one conversation, selected by an inclusive 1-based
cue range (--cues N-M), a media-clock time window (--from/--to), or the
selectors carried by a sageox:// citation URI passed as <id>. With no
selector, the first 100 cues are served and the window reports truncated.

The requested range is always served from the current transcript; the
envelope reports revision_requested/revision_current and a pinning status
(pinned | unpinned | revision_mismatch) so citation-followers see drift
honestly instead of silent renumbering.

```
ox conversation transcript <id> [flags]
```

### Options

```
      --cues string     inclusive 1-based cue range, N-M (or a single cue N)
      --format string   output format: json|text (default "json")
      --from string     window start on the media clock (hh:mm:ss[.mmm] or a duration like 3m12s)
      --full            serve the entire transcript — intended for humans; agents should request windows (--cues or --from/--to)
  -h, --help            help for transcript
      --text            shorthand for --format text
      --to string       window end on the media clock (same forms as --from)
```
