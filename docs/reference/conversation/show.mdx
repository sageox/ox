## ox conversation show

Show one conversation's metadata and human summary

### Synopsis

Metadata plus the human summary of one conversation. A conversation without a summary yet is data, not an error: the summary block reports available=false with a typed reason. Accepts cnv_<uuidv7>, rec_<uuidv7>, a sageox:// citation URI, or a pasted sageox.ai recording link (…/c/rec_…, …/recordings/rec_…).

```
ox conversation show <id> [flags]
```
