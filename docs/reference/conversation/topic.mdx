## ox conversation topic

Show one distillation topic's atoms

### Synopsis

One topic of a conversation's distillation, with all of its atoms — kind, signal, text, quote, source citation URIs, and confidence. Topics are addressed by the exact tp_<uuidv7> copied from ox conversation topics. The default view is projected-current; --include-superseded adds tombstones so succession chains are auditable.

```
ox conversation topic <id> <tp_id> [flags]
```

### Options

```
      --format string        output format: json|text (default "json")
  -h, --help                 help for topic
      --include-superseded   also serve superseded atoms as tombstones (valid_from/valid_to/superseded_by)
      --text                 shorthand for --format text
```
