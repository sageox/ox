## ox conversation list

List the active team's recorded conversations

### Synopsis

Browse the active team's conversations from the local team-context index — newest first, capped at --limit. Each row carries the ids, title, date, participants, and counts an agent needs to decide whether to descend a rung.

```
ox conversation list [flags]
```

### Options

```
      --format string   output format: json|text (default "json")
  -h, --help            help for list
      --limit int       cap the number of conversations returned (default 20)
      --since string    only conversations recorded on or after this instant (RFC3339 or YYYY-MM-DD)
      --text            shorthand for --format text
```
