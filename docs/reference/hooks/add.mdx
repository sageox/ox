## ox hooks add

Register a new event hook

### Synopsis

Register a hook script to run when a daemon event fires.

The command receives the event as JSON on stdin and has a 500ms timeout.

Valid events:
  agent.idle
  agent.registered
  daemon.started
  daemon.stopped
  murmur.critical
  murmur.received
  session.available
  session.started
  session.stopped
  session.uploaded
  sync.completed
  sync.failed
  * (matches all events)

Examples:
  ox hooks add murmur.received 'notify-send "Murmur" "$(cat)"'
  ox hooks add session.uploaded 'curl -X POST https://slack.example.com/hook -d @-'
  ox hooks add '*' 'logger -t ox'

```
ox hooks add <event> <command> [flags]
```
