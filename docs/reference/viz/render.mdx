## ox viz render

Render a parameterized visualization from JSON data

### Synopsis

Render a parameterized catalog pattern from JSON into an HTML/SVG
fragment. ox computes geometry; the AI coworker supplies only data. Inspect the
required shape with 'ox viz <id>'.

```
ox viz render <id> [flags]
```

### Options

```
      --data string   JSON data file for the pattern (use - for stdin)
  -h, --help          help for render
```
